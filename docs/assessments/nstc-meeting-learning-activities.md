# 多重 AI Agent 創造力學習平台 — 系統現況與學習活動規劃確認事項

會議用文件（草稿）
日期：2026-07-13
用途：與合作教授（創造力領域學者）會議，聚焦「創造力學習活動如何在平台上安排」

---

## 零、會議目標

平台的技術骨幹大致就緒，接下來最需要**領域專家定調**的是「學習活動的教學設計」。本次會議希望產出：

1. 三大創造力面向（擴散性思考、頓悟性思考、遠距聯想）的**活動互動形式**拍板（尤其：文字作答 vs 視覺部件操作）。
2. 創造力**四維評分規準（rubric）**的初版，這是分析代理（AA）能否運作的前提。
3. 「最小線索引導」與「僵局判定」的**操作型定義**。
4. 兩種教學模式／兩種學習策略的**可操作差異**。

---

## 一、系統現況（對學習活動設計的意義）

以下不談技術細節，只講「平台目前能為活動做什麼、哪些限制會形塑你的設計」。

### 1.1 目前已具備、可直接用於活動

| 能力 | 對活動設計的意義 |
|---|---|
| 即時多人討論室 | 2–3 人小組真人學生（可用連結加入，免帳號）＋多個 AI 角色，在同一房間文字互動、逐字即時顯示 |
| 四種 AI 角色可各自設定人格 | 教師代理（TA）、學生代理（SA，同儕催化）、分析代理（AA，靜默觀察診斷）、設計代理（DA），皆為不同「指令＋人格」的 agent |
| 觀察者（AA）靜默診斷 | AA 可全程觀察但不發言，產出「診斷筆記」只有教師看得到；教師可選擇性把提示放行到討論室或特定 agent |
| Agent 間審批 | 可設「某 agent 動作前需另一 agent 批准」——可用來編排「SA 介入前先問 TA」 |
| 全程對話留存＋匯出 | 所有師生與 agent 發言逐則留存，可匯出供研究分析 |
| AI 身分揭露設定 | 可設定是否向學生揭露「房內有 AI 參與者」，對應倫理要求 |
| LLM：Gemini 等 | 已可用自帶金鑰串接 Gemini 等模型 |

### 1.2 會「形塑」活動設計的關鍵限制（設計時必須先納入）

這幾點直接決定活動能怎麼設計，是本次會議最該先釐清的：

1. **互動目前是「文字聊天」。** 討論室是文字／markdown。像「拖曳、旋轉、重組部件」這種**視覺操作介面目前沒有**。
   - 影響：部件類任務要嘛設計成「用文字作答」（例如直接打出目標字、或用文字描述操作），要嘛需另建「部件操作畫布」（屬較大工程）。
   - **這是最需要先定調的一點**，決定工程規模與時程。

2. **AA 的即時干預目前是「半自動、教師在環」。** AA 能診斷，但把提示送進討論室**目前需教師按放行**；計畫圖裡「AA 偵測僵局→**自動**發送給 TA／SA」的全自動迴路要另建。
   - 影響：活動的提示機制要先決定——是「教師看診斷再放行」（貼近大專生 MVP，現成），還是要投資做「全自動即時干預」（教授計畫的賣點，需開發）。

3. **多個 agent 的發言順序沒有中央仲裁。** 預設情況下每則訊息會讓所有在場 agent 一起回應。要「TA 主導、SA 適時介入」的**有序流程**，需靠設定（@點名／觸發規則）或預先編排的流程腳本。
   - 影響：每個活動的「互動腳本」（誰先、誰後、何時介入）要**定義得夠清楚**才能落地。

4. **創造力四維評分尚未內建。** 流暢／變通／原創／收斂的自動評分要建，而且**需要領域專家提供評分規準**。這正是本次會議該帶回的產物。

5. **評分可重現性需補強。** 目前模型輸出有隨機性；要做「AA 評分 vs 人類評分」的 Kappa 一致性校驗，需先補「固定模型參數」（工程小改）。

## 二、學習活動規劃 — 要與合作教授確認的事項

以下每項都標注「為什麼系統需要這個決定」。**A 至 F 為教學設計主軸。**

### A. 活動的互動形式與載體（最優先）

- **A1.** 三大面向的每種任務，是「純文字作答」還是需要「視覺部件操作」介面？
  - 可用文字的：字詞拼圖（遠距聯想，打出關聯字）、破音字詞轉換（打出目標字／詞）、字彙聯想重組
  - 需釐清的：拆字蓋樓、部件旋轉與變形、變形部件轉換、部件聯想重組——**能否以文字描述作答**（如「把『辛』左半再拆解，答『X』字」），還是教學上一定要「看得到、能拖曳旋轉」？
- **A2.** MVP 階段是否可先**全部文字作答**，把視覺互動列為第二階段？（若可，時程與工程大幅縮小）
- **A3.** 若某些頓悟／部件任務「非視覺不可」，優先做哪一兩個？

### B. 每個活動單元的教學流程腳本（turn structure）

- **B1.** 一個單元的完整流程：誰出題（TA）→ 學生如何作答 → SA 何時介入 → AA 何時診斷 → 提示何時／如何給。請以「一個具體單元」走一遍。
- **B2.** 個人式 vs 合作式的流程差異（合作式如何落實「積極互賴」）。
- **B3.** SA（催化劑）的行為界線：故意提出低原創／錯誤答案的**頻率與強度**？何時該停止誤導、承認被說服？（計畫寫 SA 會「故意拖延僵局的解決」，需界定尺度以免變成干擾）

### C. 創造力評量與評分規準（本次會議核心產物）

- **C1.** 流暢／變通／原創／收斂**四維，在每一種任務上的操作型定義與評分規準（rubric）**。例如：拆字蓋樓的「變通」＝不同結構變化類別數？「原創」＝罕見結構的判定門檻？
- **C2.** 評分是**即時形成性**（當場回饋給學生／教師）還是事後？可接受的延遲到幾秒？
- **C3.** 「原創性／語意距離」如何界定——對照 CRRAT／CWRAT 常模、現代漢語語料庫、詞彙聯想常模？需要哪些既有資料，由誰提供。
- **C4.** 前後測與延宕後測用哪些工具（CRRAT／CWRAT／CCRAP／有限解答擴散思考測驗）？**在系統內施測還是外部**？與訓練任務如何區隔以避免練習效應？

### D. 頓悟訓練的「最小線索引導」協定

- **D1.** 「僵局（impasse）」的**操作型定義**：以什麼判定？平台無眼動，只能用**行為代理**——停滯時間、重複錯誤次數、嘗試次數、策略轉換點。請定閾值（如「1 分鐘內重複同型錯誤 3 次」）。
- **D2.** **提示階梯**：從最模糊到最具體的線索層級，每種任務各要幾階、每階內容為何。（例：破音字轉換→「先忽略語義」→「想想這個字的其他讀音」→示範一組）
- **D3.** 觸發時機與**頻率上限**（避免過度介入而破壞「啊哈」經驗）。

### E. 兩種教學模式／兩種學習策略的操作定義

- **E1.** 個人式 vs 合作式：小組人數（2–3）、合作結構如何在討論室落實。
- **E2.** AI 擔任教師（TA 權威引導）vs AI 擔任學生（SA 同儕催化）：兩者的**介入方式、話語風格、權限**具體差在哪。
- **E3.** 這些差異如何轉成「可設定的 agent 指令」——這決定 DA 能否自動生成 TA／SA 的指令。

### F. 題庫與難度漸進

- **F1.** 16 個單元的**主題排序與難度漸進**原則。
- **F2.** 題目來源與**難度校準**：沿用既有 CRRAT／CCRAP 常模？新編？由誰編製與審核？
- **F3.** 每單元題數、是否**依學習者盲點個人化出題**（系統可依歷程資料調整，但需規則）。

### G. 倫理與資料

- **G1.** AI 身分揭露的**時機與方式**（何時、如何告知學生 SA 是 AI）。
- **G2.** 知情同意、去識別化、資料保留期限。
- **G3.** IRB（人文處行為科學研究）所需的系統面配合。

### H. 成功指標（尤其大專生 MVP）

- **H1.** 系統面：AA 評分與人類評分的一致性（Cohen's Kappa）門檻。
- **H2.** 教學面：教師認知卸載（NASA-TLX／反應時間）、學生前後測進步。
- **H3.** 這些指標各要在系統裡蒐集到什麼資料——需回推到活動設計。

---

## 三、建議會議先聚焦的三個決定

時間有限的話，先敲定這三個「最卡、最影響下游」的：

1. **活動載體**：文字作答 vs 視覺部件操作（→ 決定工程規模與時程；建議 MVP 先文字）。
2. **提示／干預機制**：教師在環半自動 vs 全自動 AA→TA（→ 決定研究定位與工程量）。
3. **四維評分規準（rubric）**：由合作教授這邊定初版——**這是本次最該帶回的產物**，AA 沒有它就無法運作。

- 平台已能做：真人學生小組 ＋ 教師／同儕／觀察者 AI 同室即時文字互動、全程留存、觀察者靜默診斷、教師放行提示。
